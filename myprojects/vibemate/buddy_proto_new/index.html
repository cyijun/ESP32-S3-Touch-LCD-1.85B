LVGL 组件映射

HTML/CSS 元素LVGL Widget实现建议
.lv-displaylv_obj_t *screen360×360 主屏对象，圆形裁剪由显示驱动处理
.lv-labellv_label所有文本标签，使用内置字体 10–16px
.lv-btnlv_btn + lv_label圆形按钮：半径 24px，边框 1px
.lv-arc-track / .arc-wraplv_arc属性环：背景弧 + 前景弧，半径 13px
.stat-bar-tracklv_bar线性进度条：高度 3px，圆角
.pet-spritelv_imgASCII 精灵需预渲染为 C 数组位图 (LV_IMG_CF_ALPHA_8BIT)
.speech-bubblelv_obj + lv_label圆角矩形容器 + 文本，底部三角用 lv_line
.pet-ringlv_arc 或 lv_line装饰性细圆环，可选动画

设计令牌

  • 画布：360×360 px，圆形边界（显示驱动负责裁剪四角）
  • 安全边距：16px（文本/按钮不贴边，避免圆角裁切）
  • 主色：--accent: #3DD9D0（青色，用于高亮、进度、交互反馈）
  • 背景：#0A0A0F（深色，OLED 省电，对比度高）
  • 字体：系统无衬线 + 等宽字体（LVGL 中映射为内置字体）
